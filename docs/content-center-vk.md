# VK: первая версия источника контент-центра

## Подключение

В «Социальных сетях» добавьте HTTPS-адрес открытого сообщества заказчика.
После сохранения открывается информация об источнике. Подтвердите право использовать
собственные публикации заказчика для AI-обработки в этом workspace и нажмите
«Подключить сообщество». Сотрудник не вводит ключ заказчика.

Один раз администратор Wispo сохраняет **сервисный ключ приложения компании**
в «Настройках платформы → ВКонтакте». Раздел доступен только `WISPO_ADMIN`.
Затем указывает адрес открытого сообщества заказчика и нажимает «Проверить доступ VK».
Проверка читает описание и одну запись, не запускает AI и не сохраняет материал.
Сохранение ключа само по себе не означает, что реальный доступ проверен.

Используется VK API 5.199: `groups.getById` проверяет существование и открытость
сообщества, `wall.get` с `filter=owner` проверяет доступ к записям. Для новых
подключений права администратора сообщества не требуются. Оба метода поддерживают
service token в официальной схеме VK; фактический доступ зависит от приложения,
действующего ключа и конкретного сообщества. Ключ сообщества и access token VK ID
не являются заменой. Создание приложения и получение сервисного ключа выполняются
в кабинете VK владельцем приложения. Не используйте сторонние сервисы выдачи
ключей и не передавайте ключ в чат или URL.

Проверка привязана к конкретному сообществу, а не к произвольной странице.
Профили людей, закрытые сообщества и ссылки на отдельный пост не поддерживаются.
Принадлежность заказчику подтверждает сотрудник, API её автоматически не доказывает.
Открытость и идентичность сообщества повторно проверяются при каждом сборе. Если короткий
адрес начал вести на другое сообщество, сбор останавливается.

## Что собирается

- Название, описание, статус и сайт сообщества.
- Собственные текстовые записи за 180 дней и закреплённая запись (даже старше).
- До 500 записей стены за обход, пакетами по 100; до 700 000 символов исходного
  текста. Достижение предела явно сохраняется в ограничениях снимка.
- Дата и постоянный адрес каждой записи. Дата публикации не доказывает актуальность
  цен или условий; это явно передаётся следующему этапу анализа.

Репосты, записи других авторов, записи только с вложениями и точные повторы текста
не включаются. Комментарии, переписка, подписчики, текст изображений, видео, аудио
и документы-вложения не читаются. Блок «О сообществе» тоже считается материалом,
поэтому количество материалов не равно количеству постов.

Это программный отбор по периоду, авторству и наличию текста, не AI-классификация.
Проверка каждой записи и причина исключения видны в сохранённом снимке.

## Очередь и версии

«Обновить сбор» создаёт задачу только сбора. Он не вызывает DeepSeek, не меняет
задачу пользователя и не создаёт версию итогового документа.

«Запустить агента» заново собирает актуальное окно VK вместе с остальными
источниками. Их тексты затем проходят существующее разбиение и промежуточные
реестры. Инкрементальный кеш AI-анализа публикаций в первую версию не входит.
Сохранённые версии результата и их снимки источников остаются неизменными.

Ошибки VK и частичный результат сохраняются в охвате. Если доступ к стене прервался,
доступное описание сообщества не выдаётся за прочитанный архив публикаций.

## Ключи и доступ

Ключ отправляется из браузера в CMS по HTTPS, затем только на фиксированный
`https://api.vk.com/method/…` в POST-теле. Редиректы запрещены. В БД хранится
AES-256-GCM ciphertext с отдельной привязкой к глобальному подключению VK; используется серверный
`AI_ENCRYPTION_KEY`. Нельзя логировать тела запросов подключения или ответы VK,
которые способны повторить ключ. API статуса возвращает только факт подключения,
готовность общего подключения, название сообщества и дату. Ключ не включается в
очередь, снимки и запросы к AI и не возвращается даже администратору.

Подключением управляют сотрудники с существующим доступом к workspace.
Подключение и отключение запрещены во время его активной обработки. Смена адреса
удаляет привязку источника; удаление материала удаляет подключение каскадно.
«Отключить VK» удаляет привязку и текущий снимок, но не переписывает старые документы.
Глобальный ключ при этом не меняется. Его удаление администратором запрещает новые
сборы через общий ключ, но сохраняет снимки и версии. Уже выполняющийся запрос может
завершиться с ранее полученным ключом. Смена ключа во время проверки подключения
обнаруживается по ревизии: неподтверждённая привязка не записывается.
Для прекращения действия самого ключа его нужно также отозвать в VK.

Миграция сохраняет старые зашифрованные пользовательские ключи с привязкой к
workspace/материалу. Для них по-прежнему проверяется `is_admin`; после отключения
и повторного подключения источник переходит на глобальный ключ. Новые
пользовательские ключи в API источника больше не принимаются и не сохраняются.

## Проверка выпуска

Автоматические проверки используют фиктивные ответы VK, не реальные ключи и не
платные AI-вызовы. Они покрывают права workspace, подтверждение согласия, шифрование,
привязку ключа, очередь без AI, изменение адреса, удаление, отбор и ограничения.
Реальный успешный сбор проверяется отдельно после ввода сервисного ключа приложения компании.
