## Границы реализации

Работа продолжается в `feature/content-center-preparation-mvp`, без изменения `main` и рабочей копии второго разработчика. AI-провайдер не подключается по прямому указанию заказчика. Не добавляем общий AI-чат, исследования, генерацию статей, клиентские формы и новые форматы экспорта.

## Уже реализовано

- Материалы workspace: текст, TXT/Markdown UTF-8, одна публичная HTTPS-страница; добавление, изменение, удаление. Перечень форматов в ТЗ не конкретизирован; текущие ограничения импорта явно показаны пользователю.
- Материалы фиксируются на момент запуска, а не перечитываются во время обработки. Постоянный паспорт источников версии не хранится.
- Задача пользователя и модальное окно промптов: список слева, выбранный текст справа, создание и копирование без изменения оригинала.
- Явный запуск, очередь, защита от повторного одновременного запуска, сохранение текущего результата до успеха следующего.
- История и документ как отдельные страницы; неизменяемые версии; восстановление старой версии создаёт новую с подтверждением.
- Документ для чтения, без ручного редактирования результата.
- Изоляция workspace и проверка доступа на сервере.

## Дельта этой поставки

- [x] В сценарии «У меня нет материалов» передаётся только инструкция: ни материалы, ни прежний документ не включаются в контекст. Регрессия с удалением последнего материала сохраняет прежние версии, но не передаёт их в новую задачу.
- [x] Голосовой ввод инструкции по явному действию пользователя, с остановкой и понятными ошибками/ограничениями браузера. Не включать микрофон автоматически; не сохранять аудио в CMS. Разрешение microphone=(self) ограничено HTML-оболочкой CMS (`location = /`); публичные превью, API и статика сохраняют запрет.
- [x] Основные этапы текущего запуска отображаются по реальному статусу очереди/обработки/сохранения, без вымышленных процентов и внутренних этапов модели.
- [x] Целевые регрессии: 8 интеграционных тестов в отдельной PostgreSQL, 6 тестов диктовки/статусов/разрешений, ESLint затронутых TS/TSX-файлов, TypeScript веб-приложения.

Серверные сборки API и Web, проверка nginx и проверка опубликованного интерфейса выполняются при выкладке. Реальная диктовка с микрофоном пользователя и реальный AI-запуск не имитируются тестовыми ответами на общем сайте.

## Отложено самим ТЗ / прежней договорённостью

Реальный AI-адаптер; дополнительные форматы и внешние сервисы экспорта; дополнительные правила формирования содержания; создание клиентской формы. Браузерное распознавание речи не означает подключение AI-провайдера обработки материалов. Поддержка диктовки зависит от браузера и разрешения пользователя; отсутствие поддержки не должно блокировать ввод текста и остальные действия.
