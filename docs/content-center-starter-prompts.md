# Стартовые промпты Контентного центра

Черновое наполнение по названиям из прототипа, подготовлено 19.09.2026. Это рабочие заготовки для проверки и правки заказчиком, а не утверждённая методология.

Полные тексты: [seed-content-center-prompts.cjs](../deploy/seed-content-center-prompts.cjs), массив `prompts`.

| Название | Ожидаемый результат |
| --- | --- |
| Анализ компании | Профиль бизнеса, предложение, аудитория, подтверждённые преимущества, рекомендации по контенту |
| Анализ интернет-магазина | Ассортимент, сценарии выбора, полнота карточек, условия покупки и контентные задачи |
| Анализ лендинга | Цель страницы, смысловые блоки, предложение, возражения, CTA и редакторские рекомендации |
| Без материалов | Первичные вопросы или предварительный бриф по описанию пользователя; без вымышленного бизнеса |
| Структура статьи | Интент, цель, H1/H2/H3, тезисы, вопросы, SEO-черновик и данные для проверки |
| Анализ конкурентов | Сопоставление предоставленных материалов по единым критериям, ограничения выборки и вопросы для исследования |

Во всех текстах: не выдумывать факты и источники, отделять факты от гипотез, отмечать «Нет данных», не считать URL прочитанной страницей, не переносить секреты и избыточные персональные данные в результат. Промпты не включают сведения конкретного клиента и не объединяют данные workspace.

## Наполнение

Административный скрипт запускается в API-контейнере, получает только явно указанные UUID workspace. Без `--apply` показывает план без записи. С `--apply` добавляет недостающие названия в одной транзакции; существующие тексты не обновляет, учитывает лимит 100 промптов, использует тот же workspace-lock, что штатное создание промпта. Повторный запуск не создаёт дубликатов. Не запускает AI, не меняет материалы, черновики задач и результаты.

При первоначальном наполнении целевые пространства: Crazy Studio, Luminova, ПАК. В каждом — независимая копия шести текстов. Для новых workspace автоматического наполнения не добавлялось: это контентная правка без изменения приложения.

В текущем интерфейсе «Использовать в задаче» копирует промпт в редактируемое поле инструкции. Правки там не меняют библиотечный шаблон. Создание нового библиотечного промпта уже поддерживается; редактирование сохранённого шаблона отдельной кнопкой в этой задаче не добавлялось.
