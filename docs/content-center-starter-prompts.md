# Стартовые промпты Контентного центра

Черновое наполнение для общего раздела «Подготовка информации», подготовлено 22.09.2026. Это рабочие заготовки для проверки и правки заказчиком, а не утверждённая методология. Раздел собирает общую картину компании; отдельное исследование рынка и конкурентов выполняется в следующем разделе.

Полные тексты: [seed-content-center-prompts.cjs](../deploy/seed-content-center-prompts.cjs), массив `prompts`.

| Название | Ожидаемый результат |
| --- | --- |
| Анализ компании | Единый профиль компании: деятельность, продукты и услуги, клиенты, коммуникация, отзывы, сильные стороны, ограничения и пробелы |
| Анализ интернет-магазина | Ассортимент, сценарии выбора, полнота карточек, условия покупки и контентные задачи |
| Анализ лендинга | Цель страницы, смысловые блоки, предложение, возражения, CTA и редакторские рекомендации |
| Без материалов | Первичные вопросы или предварительный бриф по описанию пользователя; без вымышленного бизнеса |
| Структура статьи | Интент, цель, H1/H2/H3, тезисы, вопросы, SEO-черновик и данные для проверки |
| Отзывы и обратная связь | Повторяющиеся положительные и отрицательные темы, вопросы клиентов, точки внимания и пробелы в отзывах |
| Общая сводка компании | Большая итоговая выжимка по всем материалам для команды и следующих задач |

Во всех текстах: не выдумывать факты и источники, отделять факты от гипотез, отмечать «Нет данных», не считать URL прочитанной страницей, не переносить секреты и избыточные персональные данные в результат. Промпты не включают сведения конкретного клиента и не объединяют данные workspace. В общей подготовке не заявляются выводы исследования рынка, рейтинги конкурентов, поисковый спрос или прогноз эффективности.

## Единая библиотека платформы

Промпты — глобальные настройки, а не данные отдельных workspace. Администратор создаёт, редактирует и удаляет их в «Настройки платформы → Промпты». Сотрудники выбирают их в подготовке информации и создании контента; оба окна заново читают один список при открытии. Новые workspace получают доступ к той же библиотеке без копирования.

«Использовать в задаче» копирует текст в инструкцию конкретного запуска. Изменение или удаление шаблона не меняет уже скопированный текст, черновики, прошлые запуски и результаты. Материалы и результаты workspace остаются изолированными. Не включайте в общие шаблоны данные конкретного клиента.

Миграция 1790486400000 переносит только точные известные стартовые тексты (название + UTF-8 MD5), сводя одинаковые копии к глобальным записям. Миграция 1791264000000 обновляет только нетронутый стартовый «Анализ компании», переименовывает нетронутый конкурентный шаблон в «Отзывы и обратная связь» и добавляет «Общая сводка компании». Произвольные пользовательские тексты из workspace автоматически не публикуются и не перезаписываются. Старый cc_prompts больше не читается приложением и оставлен только для восстановления; старый POST отвечает 410 без записи. Изменения общих промптов защищены ревизией от перезаписи другим администратором.

Для нового окружения: административный seed-content-center-prompts.cjs запускается в API-контейнере с --global-library; без --apply показывает план, с --apply добавляет недостающие названия, не перезаписывая существующие. Лимит — 100 промптов. Старые --workspace больше не поддерживаются. Скрипт не вызывает AI.

Проверка: миграция не раскрывает изменённые/частные тексты, права чтения/редактирования, конфликт ревизий, общий список между workspace, неизменность скопированных инструкций и результатов, идемпотентное наполнение.
